How these figures are calculated

Active Vendors, Facility counts, Supplier readiness, rent owed and cash collection are different populations and measures. MarketMaster sees only the assigned Market. A global SuperAdmin rollup requires cross-Market deduplication, and invoices/payments must use a reconciled, consistent cohort. Do not count held financial evidence as verified; do not interpret recorded occupancy as physical inspection. The final UI must reflect the current authoritative source and an as-of timestamp.
